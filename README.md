# Amit Dubey Portfolio

A modern, responsive portfolio website built using React, Vite, and Framer Motion. 
It highlights the skills, projects, and professional background of Amit Dubey, a Software Engineer and Full Stack Developer.

## Features
- **Interactive UI**: Built with Framer Motion for smooth and engaging animations.
- **Responsive Design**: Designed to work seamlessly across desktop and mobile devices.
- **Glassmorphism Aesthetic**: Uses modern glass container styling for a premium feel.
- **Downloadable Resume**: Direct link to download the latest professional resume.

## Technologies Used
- React.js
- Vite
- Framer Motion
- React Icons

## Getting Started

To run the project locally:

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Documentation
- The portfolio is continuously updated with the latest projects and a current resume.
- Profile picture and resume are stored in the `src/assets` directory and referenced in `App.jsx`.
